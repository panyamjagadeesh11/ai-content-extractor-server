# ai-content-extractor-server
The server-side component of the AI-powered Content Extractor. Built with Node.js and Express, this API handles requests from the frontend, scrapes website content, and leverages the Gemini AI model for summarization.

## Technologies Used

* **Node.js:** JavaScript runtime environment.
* **Express:** Minimalist web application framework for Node.js.
* **`@google/generative-ai`:** Google's official Node.js client library for interacting with the Gemini API.
* **Axios:** Promise-based HTTP client for making requests (used for fetching URL content).
* **Cheerio:** Fast, flexible, and lean implementation of core jQuery designed specifically for the server (for parsing HTML).
* **dotenv:** Loads environment variables from a `.env` file.
* **cors:** Middleware for handling Cross-Origin Resource Sharing.

## Setup Instructions

To run the backend server locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone <backend-repository-url>
    cd ai-content-extractor-server
    ```
    (Replace `<backend-repository-url>` with the actual URL of your backend GitHub repository)

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure environment variables:**
    * Create a `.env` file in the root of the backend directory.
    * Add your Google Gemini API key:
        ```env
        OPENAI_API_KEY=YOUR_ACTUAL_GEMINI_API_KEY
        ```
        **Important:** Replace `YOUR_ACTUAL_GEMINI_API_KEY` with your actual API key from Google AI Studio or Google Cloud Console. **Do not commit this `.env` file to your repository for security reasons.** It's included in `.gitignore`.

4.  **Run the backend server:**
    ```bash
    node server.js
    ```
    The server will start and listen on the port specified in your `server.js` file (default is usually `8080`). You should see a message in the console indicating that the server is running.

## API Endpoints

The backend provides the following API endpoint:

### `POST /api/summarize`

* **Description:** Accepts a JSON payload containing a `url` and returns a JSON response with the original URL, extracted text (truncated), a 3-point summary (`summary`), and key points (`keyPoints`) generated by the Gemini AI model.
* **Request Body (JSON):**
    ```json
    {
      "url": "[https://www.example.com/article](https://www.example.com/article)"
    }
    ```
* **Response Body (JSON):**
    ```json
    {
      "url": "[https://www.example.com/article](https://www.example.com/article)",
      "extractedText": "...", // First 500 characters of the extracted text
      "summary": "A concise summary of the article.",
      "keyPoints": [
        "Key point 1.",
        "Key point 2.",
        "Key point 3."
      ]
    }
    ```
* **Error Handling:** The API returns appropriate HTTP status codes and error messages for invalid requests or failures during content extraction or AI processing.
